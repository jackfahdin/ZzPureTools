# 信息栏实现计划

> 使用 subagent-driven-development、test-driven-development 和 verification-before-completion。延续已授权的 FluentUIStyle 迁移，在当前工作树执行，用户说“提交”后才提交。

**目标：** 迁移参考 ExInfoBar 与 ExInfoBarHost，提供完整信息栏及窗口级通知示例。
**来源结论：** Qt Widgets 没有 InfoBar 原生类。参考继承 QWidget，使用 Qt 公共标签、按钮、布局、绘图和动画实现。现有 ZzMessageBar 只发 closeRequested、不自动隐藏；保留其 API 与行为，新增 ZzInfoBar 及 ZzInfoBarHost。
**架构：** ZzFluentUI 导出类、PIMPL、显式 Q_PROPERTY、中文 Doxygen；布局绘制、展开状态、浮动通知队列分离。info-bar 路由紧接 timeline，总路由数39。Expander 属于下一组件，不在此次范围。
**技术栈：** C++20、Qt6.8+ 公共 API、Linux GCC / Qt6.11.1，build/linux-gcc-debug。
