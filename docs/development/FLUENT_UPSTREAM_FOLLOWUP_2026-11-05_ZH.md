## 已有能力：不重复新增

| 上游能力 | 框架对应能力 | 本轮结论 |
| --- | --- | --- |
| QSplitter 胶囊手柄（`951accc`、`fb227d1`） | `ZzFluentStyle`，本地 `2dba03c` | 已处理 QSplitter；不能据此宣称所有 QDockWidget 分隔行为也完全一致 |
| 频谱物理、倒影、声道下混、彩虹配色（`dc8bd56`、`25a76da`） | `ZzAudioSpectrum`、分析器和流式输入，本地 `c441672`、`8b0bd8e` | 已实现独立库能力，实际 PCM→FFT 安装消费者已有覆盖 |
| 字体图标（`aae2ae3`） | foundation 的 `ZzFontIcon` 和 `ZzIconDescriptor` | 已有统一图标体系，后续控件应复用字体图标，避免用文本字符替代 |
| 轮播（`d0a6911`） | `ZzCarouselView` | 已有组件；不因上游新增类而重复创建 |
| 范围滑块、光束、电平表、液体球、仪表、环形进度、时间轴 | 同名 Zz 控件及多系列仪表／进度环 | 已有能力；后续按具体行为差异补齐，不能仅凭类名认定完全一致 |
| 内容对话框、信息栏、导航、日历、颜色选择器 | 对应 Zz 控件和 Qt 样式适配 | 保留框架组件边界与现有回归；颜色对话框不自动跟随上游改成另一种窗口形式 |

## 值得评估的新能力

| 候选 | 与现有组件的关系 | 建议 |
| --- | --- | --- |
| Tour 分步引导 | 上游 `ExTour` 有目标镂空遮罩、步骤序列、上一／下一步、完成／取消；`ZzTeachingTip` 只负责单个提示 | 先完成提示框基础交互，再设计独立引导控制器；明确目标消失、页面切换、焦点和高 DPI 行为 |
| 带动画的页面堆栈 | 上游 `ExStackedWidget` 用页面快照滑动；`ZzPanelStack` 是面板容器，不是同类页面切换 API | 可复用价值高，但需验证快速切换、页面销毁、尺寸变化、OpenGL／视频页面快照限制及减少动态效果 |
| TimerDial | 上游 `ExTimerDial` 接收剩余时间、总时间、运行态、预计结束时间；它本身不是计时服务 | 优先组合现有环形进度与时间文本。确认实际场景后再决定是否增加公开控件，避免把展示控件误做成计时引擎 |

## 执行约束

先修可复现缺陷，再做交互完善，最后才扩展新组件。每项独立测试和线性提交，
保留 Qt 6.8 最低版本、安装消费者、主题／RTL／无障碍和减少动态效果要求。
不修改第三方源码，不降低性能门限，不用更新截图基线掩盖回归。
需要原生 Windows／macOS 或真实显示环境验证的项目，应明确列出，不能以 offscreen
测试替代系统窗口行为验收。
