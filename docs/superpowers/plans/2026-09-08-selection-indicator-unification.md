# 选中指示条统一实施计划

**状态：** 已获批准并实施主要代码变更；本机定向回归通过，完整验收尚未完成。执行证据及剩余项见第六节。未勾选条目表示该条全部要求尚未获得确认，不表示相关实现完全未开始。

**目标：** 统一项目内表示选中项或活动项的指示条外观、内容间距和切换行为，覆盖树、列表、表格、导航、活动栏及横向选项。

**架构：** 复用 ZzItemViewVisual 的几何和绘制契约，以及 ZzSelectionIndicatorTransition 的过渡状态。视图适配负责索引、选择模型和局部重绘，绘制层不持有业务状态。不修改 Qt 原生选择行为，不引入逐行动画对象。

**技术栈：** C++20、Qt Widgets、QVariantAnimation、QPersistentModelIndex、Qt Test、CMake/CTest。

## 一、范围及审阅决策

| 范围 | 本计划处理方式 |
|---|---|
| 树形视图 | 统一树列的选中指示条，保持层级缩进、展开箭头、复选框和编辑位置 |
| 列表视图 | 统一行式列表；图标网格不新增指示条，已有标记只按实际语义归类 |
| 表格视图 | 整行选择只在首个可见视觉列绘制一条；单元格选择保持原选择范围，不强制转换为整行 |
| 导航及导航面板 | 接入统一动效和间距；主区、底区维持各自过渡所有权 |
| 活动栏 | 接入统一动效，保留左右停靠的物理边规则及已有多活动项语义 |
| Pivot、Tab 及其他选项 | 纳入选中标记清单；已有指示条统一令牌，横向滑动作为明确变体保留 |
| 拖拽插入线、焦点线、进度、滚动标记 | 用途不同，不套用选中项动画，不顺带修改 |

以下两点已随计划获准执行：

1. 纵向单选切换采用旧条收缩、新条展开；横向选项允许保留滑动，统一时长、曲线、中断和 reduced motion 规则。
2. 保留既有多选和多活动项视觉语义，不在本次擅自改为“只给 currentIndex 画条”。共用的双索引动画仅用于明确的一对一切换；批量选择变化直接进入稳定态，不能遗漏其余选中项。

## 二、统一契约

- 颜色来自主题中现有选中强调色；厚度和标准长度沿用 SelectionIndicatorThickness、SelectionIndicatorExtent，首轮不重新设计数值。
- 新增边缘留白和内容间距令牌时，追加在 ZzMetricToken 的 Count 前，不改变已有枚举编号。默认值取现有 ZzItemViewVisual 的布局数值，记录后统一其他接入点。
- 指示条圆角统一由厚度和实际长轴长度计算；短条收缩到零时不产生残余像素。
- 同一几何计算同时服务绘制、文字、图标、复选框和编辑器区域，不能只移动指示条而留下旧内容边距。
- 指示条槽位在选中前后固定，切换不造成文字和图标横跳。小行高时指示条限制在可用区域内。
- 逻辑起始侧跟随 RTL；活动栏显式物理左右边保持现有语义。表格列隐藏、拖动后重新确定指示条归属。
- 纵向过渡沿用 Normal 时长和 InOutSine；当前默认总时长为 167 ms。前半段旧条收缩，后半段新条展开。
- 快速 A→B→C、A→B→A 从当前显示比例继续。首次选中直接显示，清空选择完成旧条退出；reduced motion 立即进入终态。
- 模型重置、选择模型更换、索引删除、视图隐藏或销毁时清理旧状态；主题和布局变化后不得留下旧坐标残影。
- 每个动画所有者固定持有常量数量的动画对象，重绘只针对受影响的可见区域，不遍历整个模型。
