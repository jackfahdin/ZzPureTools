# ComboBox 外观改进

## 目标与依据

按用户要求参考本机 FluentUIStyle 的组合框：普通选择框使用按钮表面，可编辑框使用输入表面；下拉项保留清晰的悬停、选择与禁用状态。实现落在 ZzFluentStyle，所有标准 QComboBox 自动受益。

源码对比确认：现有 CC_ComboBox 提前绘制标签，而 QComboBox::paintEvent 随后还会绘制 CE_ComboBoxLabel，导致文字与图标重复绘制；普通框也错误共用输入框底线。Fusion 默认普通框使用菜单式居中弹出，而参考项目默认使用下拉列表。

## 实现范围

1. 面板与标签分离；尊重 frame 和 subControls；普通框绘制完整细圆角边框及按钮状态，可编辑框保留输入焦点线，键盘焦点使用现有焦点环。
2. 采用 Qt 原生下拉列表定位、滚动与屏幕边界避让，统一两种编辑模式。箭头随展开状态翻转；保持原有长文本、图标与 RTL 预留。
3. 保留列表的圆角状态表面与选择指示；修正高对比选中前景；以公开样式接口处理弹出边框，不访问 Qt 私有类或布局。
4. 示例展示标准、编辑、禁用和带图标状态。保留 Qt 模型、校验器、补全器、键鼠与无障碍接口。

不引入每控件动画对象、计时器或新包装类。本轮不复制参考项目依赖私有容器的弹出动画与阴影实现。
