# ZzFluentUI 数值、日期与滚轮控件视觉统一设计

## 1. 背景

`ZzPureToolsExample` 的“数值、日期与滚轮”区域目前包含
`ZzSpinBox`、`ZzDoubleSpinBox`、`ZzCalendarPicker` 和
`ZzRollerPicker`。这些控件的底层实现分别依赖 Qt 的
`QSpinBox`、`QDoubleSpinBox`、`QDateEdit`、`QCalendarWidget` 和
自定义滚轮绘制。当前实现能够满足基本的输入、键盘、主题和无障碍语义，
但边框、焦点、选中、弹层和间距缺少统一的视觉契约，导致控件在页面中显得
割裂，且部分状态的对比度和层次不够稳定。

本设计吸收以下参考项目的可复用思路，但不复制其代码，也不引入其运行时依赖：

- `XHY-ChuJian/FluentUIStyle`：使用 Qt `QStyle` 统一绘制数值控件；提供
  多种步进按钮布局；使用圆形日期单元格、今天圆环、悬停背景和明确的
  高对比文本。
- `Liniyous/ElaWidgetTools`：使用低对比基础表面、焦点强调线、中心选中带、
  前后滚轮行渐隐和独立圆角弹层建立视觉层次。

## 2. 目标与非目标

### 2.1 目标

1. 统一六个相关组件的表面、边框、圆角、焦点、悬停、按下、选中和禁用状态。
2. 保留 Qt 原生编辑、校验、日期范围、键盘导航、滚轮步进和无障碍语义。
3. 保持现有公开类名、继承关系、信号、属性和 Picker 事务行为不变。
4. 在 Linux、Windows、macOS 以及 Qt 6.8+ 的不同 DPR 下保持稳定几何和可见状态。
5. 不增加常驻动画、全局状态、每帧堆分配或与主题无关的运行时依赖。

### 2.2 非目标

- 不重新设计六个组件的公开 API。
- 不复制两个参考项目的主题管理器、字体系统或资源包。
- 不引入新的业务数据模型或 Example 专用绘制逻辑。
- 不把视觉改动扩展到与本设计无直接关系的其他控件。

## 3. 组件范围与关系

| 层级 | 组件 | Qt 基类/作用 |
| --- | --- | --- |
| 数值输入 | `ZzSpinBox` | `QSpinBox` 的 Fluent 外观封装 |
| 数值输入 | `ZzDoubleSpinBox` | `QDoubleSpinBox` 的 Fluent 外观封装 |
| 日期输入 | `ZzCalendarPicker` | `QDateEdit` 输入框和 `ZzCalendar` 弹层的组合 |
| 日期视图 | `ZzCalendar` | `QCalendarWidget` 日期网格和日期单元格呈现 |
| 滚轮视图 | `ZzRoller` | 基于 `QSpinBox` 索引语义的固定行滚轮 |
| 滚轮选择 | `ZzRollerPicker` | 多列 `ZzRoller` 的可确认弹出选择器 |

`ZzCalendarPicker` 与 `ZzRollerPicker` 的外层输入表面必须与数值输入使用同一
组视觉规则；`ZzCalendar` 与 `ZzRoller` 即使单独使用，也必须与各自 Picker
中的弹层实例保持一致。

## 4. 统一视觉契约

### 4.1 几何

- 默认输入控件高度为 36 个逻辑像素；调用方显式设置尺寸时，绘制按可用矩形
  等比收缩，不得覆盖调用方的布局约束。
- 输入表面使用 4 至 6 个逻辑像素圆角；圆角值来自现有 `ZzMetricToken`，
  不在控件中写死主题专属数值。
- 边框宽度在设备像素中保持约 1px；由 DPR 换算为逻辑宽度，避免高 DPI 下
  线条变粗或断裂。
- 所有可交互子区域必须拥有稳定矩形。悬停、按下和禁用状态只能改变绘制，
  不得改变布局尺寸。

### 4.2 颜色和状态

- 默认表面、悬停表面、按下表面、边框和强调色全部来自
  `ZzThemeSnapshot` 的现有 token。
- 普通悬停只改变局部表面填充，不绘制大面积高亮框。
- 焦点使用细强调色底线或内环；焦点环不得覆盖文字和图标。
- 禁用状态同时降低文本、图标和边框对比度，且保留控件轮廓。
- 高对比主题优先使用 `QPalette::Highlight`、
  `QPalette::HighlightedText`、`QPalette::Text` 和 `QPalette::Base`，
  确保选中日期、中心滚轮行和步进按钮仍可辨识。
- RTL 方向必须通过 `QStyle::visualRect`、`layoutDirection()` 和现有 Qt
  子控件矩形计算处理，不能用左右坐标硬编码替代。

## 5. 数值控件设计

### 5.1 绘制入口

`ZzSpinBox` 与 `ZzDoubleSpinBox` 继续使用
`ZzFluentStylePrivate::drawSpinBox()` 和相关子控件矩形函数绘制。两个公开类
只负责保留 Qt 类型语义，不在类中复制绘制逻辑。

### 5.2 输入表面

- 编辑区域占据除步进区外的全部可用宽度，并保留前缀、后缀和区域设置产生的
  文本空间。
- 默认表面为低对比边框加主题表面色；悬停时只改变表面填充。
- 获得键盘焦点时显示细强调色底线或内环，不显示白色大边框。
- `readOnly`、`NoButtons` 和禁用状态必须继续使用同一输入表面，只调整可用性
  和颜色。

### 5.3 步进按钮

- 右侧步进区默认宽度约 28 个逻辑像素，上下按钮拥有独立稳定命中矩形。
- `QAbstractSpinBox::UpDownArrows` 使用细线圆角箭头；
  `QAbstractSpinBox::PlusMinus` 使用圆角端点的加减号。
- 只有当前命中的按钮在悬停或按下时绘制局部填充。
- 当步进方向被 Qt 的 `stepEnabled()` 禁用时，按钮仍保留几何位置，但图标和
  命中行为使用禁用态。
- `QStyle::SC_SpinBoxUp` 和 `SC_SpinBoxDown` 的命中测试必须覆盖完整按钮本体，
  确保点击按钮区域任意位置均能执行步进。

## 6. 日期控件设计

### 6.1 Picker 输入表面

`ZzCalendarPicker` 继续继承 `QDateEdit`，使用 Qt 的文本输入、日期校验、日期
范围和键盘步进。日历弹层继续由唯一的 `ZzCalendar` 实例提供，不新增第二套
日期模型。

输入表面与数值控件一致，并保留日期格式化文本；右侧使用主题图标或下拉指示，
图标颜色跟随 `QPalette::ButtonText`，不把图标绘制成固定黑色或白色。

### 6.2 日历单元格

`ZzCalendarPrivate::paintCell()` 继续负责单元格绘制，规则如下：

- 日期单元格选取 28 至 32 个逻辑像素的圆形或轻圆角几何，尺寸不能超出
  当前单元格。
- 选中日期绘制强调色实心圆，文字使用 `HighlightedText`，必要时使用半粗体。
- 今天但未选中时绘制细强调色圆环；悬停时圆环内部可以增加低透明度背景。
- 普通悬停只绘制轻量圆形背景，不改变其他日期单元格。
- 非当前月份、超出日期范围和禁用日期降低文字透明度；周末不使用过强的独立
  颜色，避免日期网格颜色噪声。
- 具有焦点的选中日期增加细内环，内环不得覆盖日期文本。
- 月份标题、星期标题和翻页按钮使用与日历表面相同的颜色层次，边框必须完整
  封闭，不出现只绘制三边的残缺框。

### 6.3 语义保持

继续使用 `QCalendarWidget` 提供的日期模型、日期范围、选择信号、键盘导航和
无障碍表格角色。主题、字体、区域设置、DPR 或启用状态变化时只刷新可见单元格
和必要的几何，不重建日期模型。

## 7. 滚轮和滚轮 Picker 设计

### 7.1 `ZzRoller`

- 保留当前固定可见行数、`QSpinBox` 数值范围、键盘步进、鼠标点击和滚轮步进
  语义。
- 中心行使用低饱和强调色选中带，文字使用当前主题的高对比文本。
- 中心上下的行按距离逐级降低透明度；非中心行不使用大面积色块。
- 鼠标悬停只影响命中的行，不能改变整个滚轮容器的背景。
- 行高、可见行数、最小宽度和省略策略保持稳定，窗口调整或主题切换不能导致
  行跳动。
- 不新增 Ela 风格的常驻滚动动画、长按计时器或像素偏移状态；现有离散步进
  和对象图约束优先于动画效果。

### 7.2 `ZzRollerPicker`

- 主按钮使用与数值和日期输入一致的表面、边框、焦点和下拉指示。
- Popup 使用单层表面、完整边框、4 至 6px 圆角和单层轻阴影；不得出现重复
  套框或未封闭的四角。
- 多列滚轮之间使用低对比分隔线，列宽由内容和调用方的最小宽度共同决定。
- 确定、取消、Escape、外部点击和窗口失活继续遵守当前快照事务：确认提交
  草稿，取消或外部关闭恢复打开时的索引。
- Popup 宽度不得小于触发按钮或任一列的最小宽度；长文本使用稳定省略或扩展
  列宽，不能裁切关键内容。

## 8. 主题、DPR 与跨平台

1. 颜色只从 `ZzThemeSnapshot` 和 `QPalette` 获取；浅色、深色和高对比主题
   必须分别验证。
2. 所有线宽和圆角在绘制前根据 `devicePixelRatioF()` 转换，DPR 1.0 和 DPR
   2.0 均不能出现空白、断线或模糊边缘。
3. Linux X11、Linux Wayland、Windows MSVC、Windows MinGW 和 macOS Clang
   使用相同公开 API 和相同状态语义；平台差异只允许存在于 Qt 原生窗口和字体
   渲染层。
4. 不依赖参考项目的字体、主题单例、平台私有插件或额外资源。

## 9. 实现边界

优先在现有私有实现中完成，不新增公共类型和运行时依赖：

- `ZzFluentUI/widgets/src/private/ZzFluentStylePrivate.cpp`：输入表面、步进
  按钮和 `QAbstractSpinBox` 子控件几何。
- `ZzFluentUI/widgets/src/ZzRoller.cpp`：滚轮行、中心选中带、渐隐和悬停绘制。
- `ZzFluentUI/widgets/src/private/ZzCalendarPrivate.cpp`：日期单元格、今天、
  选中、焦点、禁用和高 DPI 绘制。
- `ZzFluentUI/widgets/src/private/ZzRollerPickerPrivate.cpp`：Popup 表面、
  列间距、按钮布局和弹层几何。
- `ZzFluentUI/widgets/src/private/ZzCalendarPickerPrivate.cpp`：仅补充需要的
  弹层属性或主题状态同步，不复制日期绘制。

如果多个实现确实需要相同的颜色混合或 DPR 几何计算，优先复用现有私有辅助
函数；只有在重复逻辑无法通过现有函数表达时，才增加私有辅助函数。不得为了
形式上的四文件结构拆出会增加调用和分配成本的公共抽象。

## 10. 测试与验收

### 10.1 行为测试

- 数值控件：整数、浮点、前缀、后缀、范围、步长、包装、只读、无按钮、禁用、
  键盘步进和 RTL。
- 日期控件：日期范围、文本格式、今天、选中、非当前月份、禁用日期、键盘导航、
  Picker 弹出和日期同步。
- 滚轮控件：固定行数、中心索引、键盘、鼠标、滚轮、循环边界和空集合。
- 滚轮 Picker：多列索引、长文本、确定、取消、Escape、外部关闭和快照恢复。

### 10.2 视觉和主题测试

每个控件至少覆盖浅色、深色、高对比度下的默认、悬停、按下、焦点和禁用状态。
截图测试必须检查：

- 绘制结果非空，且不只包含单一背景色。
- 日期圆形选中态、今天圆环和滚轮中心选中带可见。
- 数值步进按钮的两个命中矩形均存在且不重叠编辑文本。
- Popup 四角封闭，边框和阴影不重复叠加。
- DPR 1.0 与 DPR 2.0 下文字、图标和边框不裁切。

### 10.3 性能和对象图测试

- 重复主题切换、字体切换和 Palette 更新只刷新必要区域，不重建模型。
- 重复渲染和状态更新不得增加 QObject、`QAbstractAnimation` 或 `QTimer` 数量。
- `ZzRoller` 不得因为普通滚轮或悬停创建常驻动画对象。
- Popup 重复打开和关闭必须复用已有 Popup 和滚轮对象。
- 现有 Fluent 基础控件 benchmark 和对象图门禁必须继续通过。

### 10.4 验收标准

当以下条件同时满足时，视为本设计完成：

1. 六个组件在三种主题和两个 DPR 下视觉契约一致。
2. 原有公开 API、Qt 原生行为、Picker 事务和无障碍测试无回归。
3. 新增的状态、命中、截图和高 DPI 测试全部通过。
4. clang-tidy、Linux 构建和相关 CTest 通过，且没有新增常驻动画、定时器或
   明显对象图增长。
5. `ZzPureToolsExample` 的“数值、日期与滚轮”页面能够直接作为人工验收入口，
   不包含只在 Example 中生效的特殊绘制逻辑。
