# 音频频谱控件设计

用户已于本轮确认，按此规格实现。

## 目标与选择

用户选择功能完整、视觉效果优先。采用 KissFFT 分析 PCM，新增
`ZzAudioSpectrum`，参考 FluentUIStyle `fb227d1` 的频谱表现，适配项目主题、
生命周期、线程和安装约束。频谱展示与现有 `ZzAudioLevelMeter` 并存：前者
显示频率分布，后者显示各声道整体电平。

比较过的方案：

| 方案 | 收益 | 成本 | 结论 |
| --- | --- | --- | --- |
| KissFFT + 独立分析与呈现 | 成熟 FFT、直接接收 PCM、完整视觉功能 | 新增小型依赖及分发记录 | 采用 |
| 自写 FFT | 无外部依赖 | 增加数值算法维护与验证成本，效果不会天然更好 | 不采用 |
| 只接收外部频带 | 控件最轻 | 每个使用项目都需要额外音频分析 | 仅作为补充输入能力 |

本轮不加入播放器、音频解码器、系统音频捕获和歌词服务。

## 结构与依赖

- 公开控件：`widgets/include/ZzFluentUI/ZzAudioSpectrum.h`，采用 PIMPL。
- 私有分析器：负责 PCM 解码、Hann 窗、FFT、功率合成、对数频带映射。
  不依赖 QWidget，便于使用已知信号做数值测试。
- 私有呈现状态：负责目标高度、当前高度、峰值、时间推进和绘制。
- 默认每次最多分析最新的一窗，每次刷新不追赶历史积压。
- `ZzFluentUI` 不增加 QtMultimedia 依赖；Example 可使用现有可选
  QtMultimedia 路径，未启用时仍可用合成信号演示。
- KissFFT 使用官方 131.1.0，修订 `8f47a67f595a6641c566087bf5277034be64f24d`。
  固定源文件及摘要，保留 `COPYING`、`LICENSES/BSD-3-Clause` 和来源记录。
  只编译所需实数 FFT 内核；不暴露第三方头文件、公共 CMake 包或符号。
- 共享与静态 SDK 都必须通过独立 consumer 链接检查；运行包和 SDK 均携带
  许可正文，更新第三方通知、安装审计与打包契约测试。

## 输入契约

- `pushPcm16Le(QByteArray)`：明确为小端、交错、有符号 16 位 PCM。
- `pushSamples(QVector<float>)`：交错归一化浮点 PCM，非有限值按零处理，
  超出 [-1, 1] 的值钳制。
- `setBandLevels(QVector<qreal>)`：外部已分析的归一化频带；数量必须等于
  `barCount`，不隐式改变布局。只在 GUI 线程调用。
- `inputMode` 显式选择 PCM 或外部频带；切换清空历史，避免两类输入争抢显示。
- PCM 格式配置在 GUI 线程设置：采样率 8000～192000 Hz，声道 1～8；
  修改格式或输入类型时清空旧窗口及不完整帧。
- 两个 PCM 推送方法允许普通工作线程使用。内部固定容量保存最新
  8 个 FFT 窗的交错样本，溢出按完整帧丢弃最旧数据；大输入只取有效尾部，
  不先无限复制或解析整块数据。不适用于硬实时回调。
- 小端字节输入保留跨调用的残余字节及不完整帧，避免分包改变分析结果。
  同一音频流由一个生产者顺序推送；多生产者不保证业务音频顺序。
- 唤醒 GUI 的排队通知合并为最多一个；FFT 与绘制在 GUI 线程执行，
  不在持有输入锁时运行 FFT 或发出信号。
- `clear()` 清空缓冲、残余帧、频带及峰值；此前已排队的唤醒不能恢复旧数据。
  调用方必须在销毁控件前停止生产者，线程安全不包含与析构并发调用。

## 分析与视觉

- 默认 64 根圆角柱；柱数可设为 8～256。FFT 默认 2048 点，提供
  1024、2048、4096、8192 四档。较大窗口改善低频分辨率，同时增加响应延迟。
- 默认频率范围 60～16000 Hz；实际范围限制在 Nyquist 频率以内。
  公开实际频带中心频率，便于接入方解释显示。
- 使用 Hann 窗及窗增益校正；窄频带进行插值，宽频带做功率聚合。
  多声道默认逐声道 FFT 后取平均功率再开方，避免反相声道抵消；
  提供平均波形下混模式供追求上游表现或降低 CPU 消耗的场景使用。
- 频率倾斜补偿作为可关闭的视觉参数，默认参考上游 +3 dB/octave，
  增益限制在 -6～+9 dB；不将此效果描述为精确的等响度校正。
- 默认显示范围 -54～-3 dB，参数可调；频带高度定位为可视化结果，
  不宣称是校准测量仪器。
- 默认彩虹配色、峰值帽和渐隐倒影开启，另有跟随主题强调色及自定义颜色。
  暴露柱间距、圆角、倒影透明度、峰值保持时长与重力参数。
- 默认约 30 ms 上升响应、200 ms 峰值保持、16 ms 刷新间隔；
  动画使用单调时钟和实际时间差，保持时长不按帧数计数。
- 隐藏或禁用时停止 FFT 与动画，输入缓冲仍受容量限制；恢复后使用最新
  完整窗口，不补播历史。无输入超过 120 ms 后归零衰减，稳定后停止计时器。
- 关闭动画或启用减少动态效果时，最新频谱直接显示，保留输入超时处理；
  持续输入期间仍按刷新间隔合并更新。
- 高对比模式默认使用高对比主题颜色而非彩虹；小尺寸下减少实际可见柱数，
  合并相邻频带显示，不产生负宽度或在绘制时改变公开频带数量。

## Example 与验证

新增频谱示例页：正弦、多音、扫频与静音信号均可直接运行；可调柱数、
FFT 点数、频率范围、彩虹/主题色、倒影、峰值和动画。已有可选音频输入
可作为补充，不作为验收依赖。不需要用户准备图片或图标。

测试先于实现，覆盖：

1. 已知频率、幅值变化、窗增益、静音、DC、Nyquist 边界以及反相双声道。
2. 奇数分包、不完整帧、非法浮点数、大数据溢出、格式切换和 clear 后旧通知。
3. 主题切换、禁用、隐藏恢复、减少动态效果、空闲停表、峰值实际保持时间。
4. 浅色/深色/高对比、彩虹、倒影、峰值、小尺寸及不同 DPI 的绘制回归。
5. 私有 FFT 与控件刷新分别计时，记录默认双声道和最高配置的耗时、
   缓冲容量与空闲活动情况；先提供测量证据，不调整现有性能门限。
6. Qt 6.8 与本机 Qt 6.11 构建，相关组件回归、Example 冒烟、共享/静态
   consumer、第三方许可证打包契约；平台 CI 结果按实际运行情况单独报告。
